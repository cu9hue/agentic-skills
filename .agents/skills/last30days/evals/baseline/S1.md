# Cursor: the last 30 days (Oct 27 – Nov 26, 2026)

**Short version:** Cursor shipped a lot this month: live apps, voice chat, multiplayer Projects and four new frontier models. But two other stories dominated the conversation. One is a security breach that ended with a backdoored Claude Code extension in Cursor's marketplace. The other is anger over the new SpaceX-era pricing (The X Subscription) and complaints that Cursor's own models (Grok and Composer) have gotten worse.

## What shipped

- **Design mode: Annotate** (Oct 27). You can draw on a page, edit elements and check different screen sizes as visual prompts to the agent. [X](https://x.com/cursor_ai/status/2115159585548021814)
- **Agent SDK** (GA Oct 20, promoted Oct 26). You define agents as code, with prompts in Markdown and tools in TypeScript, plus built-in evals. Agents wake on GitHub/GitLab/Bitbucket, Slack, webhook or cron events, and you can deploy them to Cursor or your own infrastructure. It reached 143 points on HN. [Changelog](https://cursor.com/changelog) · [HN](https://news.ycombinator.com/item?id=50273731)
- **Build Live Apps** (Nov 5). A cloud agent scaffolds a web app, sets up Postgres and SSO auth, runs security checks and deploys to a shareable URL. It is on all paid plans with cloud agents enabled. GitHub and Cursor Origin are supported now, and GitLab is "coming soon". [Changelog](https://cursor.com/changelog/build-live-apps)
- **Voice Chat with Agents** (Nov 6). You talk to your agents in a realtime call in the IDE, on web, in the Agents Window and on iOS ("Hey Siri, call Cursor"). It runs on Grok Voice and is separate from dictation. [Changelog](https://cursor.com/changelog/voice-chat)
- **Multiplayer Projects** (beta, Nov 10). Teammates share one Project with shared context, a task board, and agent-to-agent coordination across people. Cursor says its own teams run on-call this way. This was Cursor's most-bookmarked launch of the month, with about 650K views and 1.5K bookmarks. [Blog](https://cursor.com/blog/projects-multiplayer) · [X](https://x.com/cursor_ai/status/2120295553309565139)
- **New models, with CursorBench scores:**
  - Claude Fable 5.2 (Nov 9): 60% at max effort, $8/$40 per M tokens. Cursor warns that effort levels behave differently from Fable 5.1. [X](https://x.com/cursor_ai/status/2119880829212172509)
  - Gemini 4 Carbon (Nov 10): 60.4% at high effort. **It is 50% off until Nov 30** ($2/$10), then $4/$20 from Dec 1. [X](https://x.com/cursor_ai/status/2120193584670580857)

## The security incident

This was the biggest story by reach. Cursor's first post got 1.3M views, and the HN thread got 1,014 points and 553 comments.

- **Oct 29:** For about 11 hours, the cache behind Cursor's VS Code extension marketplace served a malicious copy of Anthropic's Claude Code extension (versions 2.1.312 and 2.1.313). At most 5,000 users could have received it. Open VSX itself was never compromised. [HN](https://news.ycombinator.com/item?id=50300683)
- **Nov 13 post-mortem:** Cursor says the attack started with an access key that Cursor had issued to its inference vendor Fireworks. Fireworks exposed the key. The attacker used it to copy old (mostly 2025) agent traces from non-Privacy-Mode sessions. A few traces held unredacted credentials, and the attacker used those to reach internal SaaS tools, archived non-production repos and support data. Fewer than 0.05% of users had traces exposed, and fewer than 0.01% had API credentials exposed. Cursor says Privacy Mode data, production systems and release signing were not touched. The last attacker activity was Nov 1. [Cursor blog](https://cursor.com/blog/security-incident-update)
- **What Cursor changed:** It moved all inference off Fireworks, rotated every credential and rebuilt the marketplace. BleepingComputer reports that bugs in the backdoor likely stopped it from working on many Windows and macOS machines that did not already have SSH enabled. [BleepingComputer](https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/)
- **What to do:** If you installed or updated the Claude Code extension in Cursor on Oct 29, follow Cursor's remediation steps. Cursor says uninstalling alone may not be enough.

## Pricing backlash: The X Subscription

The X Subscription launched on Oct 12, but the fallout filled November. It bundles Grok, Cursor, Grok Bot and X Premium in five tiers: Free, Plus $8, Premium $30, Super $100 and Ultra $200. Every paid tier draws on one weekly pool of Grok-model usage. That pool covers Grok 4.5–4.7 and Composer 2.5. **Third-party models (Claude, GPT, Gemini, Muse) are not in the pool.** On Premium and above they are billed at API list price from the first token. Plus and Free cannot use them at all. Legacy Cursor plans still work at their old prices, and no shutdown date has been announced. [Top5Apps explainer](https://top5apps.ai/news/what-is-the-x-subscription-grok-cursor-x-premium-bundle-tiers-what-you-lose-should-you-switch/)

The forum thread is now 20+ pages long, and it is mostly negative. [Forum](https://forum.cursor.com/t/introducing-the-x-subscription/174450?page=20)
- Users who moved from Pro+ ($60) to Super ($100) say they get less usage, not the advertised "2.25x". One user says support replied that it "can't walk through how the 2.25x figure adds up."
- Weekly resets hurt people who work in bursts. Users are asking for a monthly allowance option.
- Heavy users of third-party models call the plan "a price increase dressed up as a new plan." Several say they will stay on legacy plans or leave for Claude Code, OpenCode, Kimi Code or T3 Code.

## Quality complaints about Cursor's own models

- A Nov 5 forum thread says Auto mode and Grok 4.7 "suddenly became dumb and lazy." Several users confirm it and say they switched to Opus 5.5. [Forum](https://forum.cursor.com/t/something-s-changed-auto-mode-and-grok-suddenly-they-ve-become-dumb-and-lazy/177412)
- A Nov 21 thread reports a Composer 2.5 regression: unrequested changes, scope creep and unfinished tasks, even in short new chats. [Forum](https://forum.cursor.com/t/composer-2-5-quality-regression-unrequested-changes-incomplete-tasks-and-increased-costs/178969)
- The Nov 18 thread "After the acquisition, Cursor is turning into a use-it-and-toss-it accessory" sums up the mood: Cursor is being drained into Grok, and Composer 3 is always "in the works." [Forum](https://forum.cursor.com/t/after-the-acquisition-cursor-is-turning-into-a-use-it-and-toss-it-accessory/178705)
- The same view shows up on X in several languages. One user writes, "What happened to Cursor? It was the best in 2025." A Japanese post with about 9K views says Cursor's way back is to revive Composer and invest in Cloud Agents. [X](https://x.com/GoodLoong_Evol/status/2125966775301156943) · [X](https://x.com/kinopee_ai/status/2125631510804054438)
- Not everyone agrees. Some HN and X users say Grok and Composer feel "nearly free" on the $20 plan, and that Auto mode is about 10x faster and good enough 90% of the time.

## Ownership and politics

- SpaceX finished buying Cursor in August at an implied $60B equity value, and Cursor now helps train Grok.
- **Nov 20:** A House report says Cursor told lawmakers it will "explore phasing out" Chinese-developed open-weight models because of geopolitical risk. Composer 2 was built on Moonshot's Kimi K2.5. [CNBC](https://www.cnbc.com/2026/11/20/cursor-chinese-ai-models-geopolitical-risk.html)
