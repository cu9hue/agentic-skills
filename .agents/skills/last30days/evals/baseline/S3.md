## What's trending in AI agents (late November 2026)

The short version: agents grew managers, an identity layer, and wallets this month. Developers, meanwhile, are complaining about cost and reliability.

### 1. Manager agents that run for days

The big product pattern is a supervisor agent that splits a goal and runs a team of worker agents under a budget.

- **Cognition Devin Bots** (Nov 17): a Bot manages parallel Devin agents, keeps context for weeks, and asks people in Slack when it is blocked. Cognition added **Org Charts** on Nov 25, a single view of all your Bots. That launch post drew about 95k views and 440 bookmarks on X. [Fortune summary via ozercemkelahmet.com](https://www.ozercemkelahmet.com/articles/agent-trends-tool-gateways-manager-agents) · [Cognition on X](https://x.com/cognition/status/2125659035231780966)
- **Replit Missions** (Nov 17): you agree on success criteria and a spending cap, a swarm does the work, and an independent AI judge checks the result. [same source](https://www.ozercemkelahmet.com/articles/agent-trends-tool-gateways-manager-agents)
- **Claude Fable 5.2** (Nov 9) has orchestration built into the model. It can act as an Advisor or an Orchestrator for smaller models. Anthropic says it ran more than 1,000 subagents for eight days in one test. [AI Business Weekly](https://aibusinessweekly.net/p/ai-agent-news)
- **Perplexity Teammates** (Nov 4) and **Grok Bot 1.0** (Nov 11) put persistent agents inside Slack and Teams. [AI Business Weekly](https://aibusinessweekly.net/p/ai-agent-news) · [Extendly](https://extendly.com/post/ai-personal-agents-changed-the-world)

### 2. "Cheap worker, expensive boss" pricing

Vendors now sell models for each role. Meta's **Muse Ember** costs $0.10/$0.50 per million tokens and is built for delegated tasks. Fable 5.2 costs $8/$40. That is about an 80x gap at list price. [AI Business Weekly](https://aibusinessweekly.net/p/ai-agent-news)

The catch: on Reddit, Fable 5.2's lower per-token price did not mean a lower cost per task. Artificial Analysis measured $26.54 per task at Max effort, against $12.99 for Fable 5.1. The reason is that Fable 5.2 writes far more output and starts subagents eagerly. [Oakgen roundup of Reddit/HN reactions](https://oakgen.ai/blog/claude-fable-5-2-community-reactions)

### 3. MCP becomes the standard way in

MCP turned two years old this week, and a lot shipped around it.

- **Anthropic** (Nov 24–25): Skills over MCP is in public beta. Tasks (long background jobs) and Elicitation (the agent stops to ask you) are GA in Claude and Claude Code. [The Neuron](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-november-25-2026/) · [AgentScout](https://agentscouthq.com/news/2026/11/)
- **Google Workspace** made its MCP servers and a CLI GA. Agents must use them instead of the REST APIs, with enforcement from Feb 1, 2027. [AgentScout](https://agentscouthq.com/news/2026/11/) · [Agent Brief](https://news.agentcommunity.org/issues/month/2026-11)
- Vertical MCP servers launch almost daily: Duco (reconciliation), Alta (sales), Magister (85 marketing tools), Mesh (payments). [AgentScout](https://agentscouthq.com/news/2026/11/)
- Baseten measured about 141k tokens of tool schemas per request. Deferred tool loading cut that to about 1.3k. Tool bloat is now a real cost item. [Agent Brief](https://news.agentcommunity.org/issues/month/2026-11)

### 4. Governance: identity, gateways, and tracing

Agents are getting their own credentials and a single checkpoint for tool calls.

- **Microsoft Agent 365** (Ignite, Nov 17): every connected agent gets an Entra Agent ID, and agent traces flow into Azure Monitor on OpenTelemetry GenAI conventions.
- **LangSmith Tool Gateway** (Nov 19, beta): one managed layer for credentials, access policies, and human approval on every tool call. [both via ozercemkelahmet.com](https://www.ozercemkelahmet.com/articles/agent-trends-tool-gateways-manager-agents)
- Security vendors are buying agent-control startups. CrowdStrike is acquiring Fiddler, Cyera bought Oasis for $1B, and Cisco bought Astrix. [AI Business Weekly](https://aibusinessweekly.net/p/ai-agent-news)

### 5. Agentic commerce, timed for Cyber Week

- **ChatGPT Wallet** (Nov 13) lets OpenAI's always-on "dot" agent pay for things after a Face ID check. OpenAI is now testing dots on the $20 Plus plan. [Extendly](https://extendly.com/post/ai-personal-agents-changed-the-world) · [AgentScout](https://agentscouthq.com/news/2026/11/)
- Stripe says daily spend on Link Agent Wallet is up nearly 80x since September. Shopify now pays agents a 0.3% commission on promoted products. Visa opened Agentic Ready with 140+ partners. [Last Week in AI Agents](https://assistant-benchmark-newsletter.beehiiv.com/p/last-week-in-ai-agents-nov-23)
- Human Security expects agent traffic in Cyber Week (Nov 26–30) to reach about 150x last year's level. Meta's Muse accounts for about 70% of that traffic. [AgentScout](https://agentscouthq.com/news/2026/11/)
- Reality check: in one test of 25 assistants, only 14% of 200 shopping attempts ended in an accepted order. [Last Week in AI Agents](https://assistant-benchmark-newsletter.beehiiv.com/p/last-week-in-ai-agents-nov-23)

### 6. Computer use goes mainstream

Gemini can now operate a Mac across apps and files (Nov 19). Claude computer use is in beta for Team and Enterprise. [AgentScout](https://agentscouthq.com/news/2026/11/) · [The Agent Race](https://agentrace.org/newsletter/issues/2026-11-23/)

### What practitioners are actually saying

The launches are optimistic. The threads are not.

- **Reliability is still the bottleneck.** On TechCrunch-covered ShellBench, the best models finished only about 60% of everyday tasks, and 15.7% of runs missed a safety check. [AgentScout](https://agentscouthq.com/news/2026/11/)
- **Destructive actions.** A Claude Code post about an agent wiping app data and settings drew 3,200+ points and 1,400 comments on Reddit. [GenisisIQ Reddit digest](https://genisisiq.com/reddit/ai-coding/2026-11-08/)
- **AI-first codebases bloat.** A post about a codebase that grew roughly 3x with duplicated helpers drew 3,400+ points. [same digest](https://genisisiq.com/reddit/ai-coding/2026-11-08/)
- **Swarm skepticism.** On HN, people say multi-agent setups "build the wrong thing faster" and that juggling six agent threads is exhausting. [HN: "The new set of problems for engineers"](https://news.ycombinator.com/item?id=50605361) · [HN thread on agent fatigue](https://news.ycombinator.com/item?id=50363073)
- **Production pain is boring.** Retries and context creep are the real costs. One flaky API turned a 4-step task into 31 calls. Per-client cost tracking and "who approved this action" are still unsolved. [Agent Brief](https://news.agentcommunity.org/issues/2026-11-17-agents-attack-agents)

### Caveats

- Reddit and LinkedIn were not reachable directly. The Reddit and HN signal above comes through digests that quote the threads.
- Many figures are company claims or come from aggregator newsletters. Examples are Cognition's "10x usage" and Replit's benchmark. Check the primary source before you cite a number.
- An X post claims Switzerland confirmed five AI-agent-run cyberattacks this week. I couldn't find this on the BACS site, so treat it as unconfirmed.
