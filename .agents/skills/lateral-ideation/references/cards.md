# Cards

An original deck in the spirit of Brian Eno and Peter Schmidt's Oblique
Strategies (1975). None of these is an Eno/Schmidt card. Draw one at random
(see SKILL.md) and apply it literally.

- Make it worse on purpose, then keep the one part that got better.
- Write it for someone who will read only the last line.
- Which part would you be embarrassed to show? Start there.
- Pretend it costs a pound a word.
- Do the boring version first.
- Who loses if this works?
- Describe it to a child, then build what the child heard.
- Take the second idea, not the first.
- What does it look like broken?
- Steal the structure of something you dislike.
- Put the ending at the start.
- Make it smaller than feels reasonable.
- Ask what the quietest person in the room would cut.
- Name the rule you are following. Break only that one.
- Swap the noun and the verb.
- What would this look like if it were free? If it cost a fortune?
- Leave a gap and let it stay empty.
- Copy it out by hand and notice where you get bored.
- Make the background the subject.
- Who is this not for? Make it for them.
- Remove the thing you are proudest of.
- Find the oldest version of this idea and start from there.
- Say it as a complaint.
- Say it as a rumour.
- Give it a deadline of ten minutes.
- What is the cheapest material it could be made of?
- Point the camera the other way.
- Turn the exception into the rule.
- Write the review before you make it.
- Let the user do the part you were going to automate.
- What did people do before this existed? Do that, but better.
- Add a cost that makes it mean something.
- Make one part far too large.
- Assume the reader already disagrees.
- Do it in the order you least want to.
- Pick the detail no one asked about and follow it.
- Explain it with one object on a table.
- Imagine it in a hospital waiting room.
- Treat the error message as the main feature.
- What would make it unnecessary?
